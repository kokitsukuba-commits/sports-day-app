# 筑波大学スポデーアプリ

筑波大学のスポーツデーの待ち時間と情報を提供するWebアプリです。

## 機能

- ホーム画面：種目ごとの待ち時間を表示
- 詳細ページ：地図と種目の説明、口コミ機能（パスコード認証）
- おすすめ表示：待ち時間が少ない種目を大きく表示
- 掲示板：パスコードで投稿可能
- 連絡事項：本部からの連絡を表示

## 起動方法

1. 依存関係をインストール：
   ```
   npm install
   ```

2. 開発サーバーを起動：
   ```
   npm run dev
   ```

3. ブラウザで http://localhost:3000 を開く

## 技術スタック

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
